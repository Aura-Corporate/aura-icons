# aura_icons_example

A minimal example app demonstrating the `aura_icons` package: a grid per
style (Outline, Linear, Bold, Broken, BoldDuotone, LineDuotone) plus a
"Conversion spot-check" tab listing any Linear/Broken icons flagged by
`tool/src/conversion_validator.dart` for manual review.

Run with `flutter run` from this directory.
